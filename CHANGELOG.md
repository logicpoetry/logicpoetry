# Changelog

All notable changes to Logic Poetry. Versions are git tags.

## [Unreleased]

### 2026-09-16 — Research and creative operators (1.1.0 working version)

- Integrated 26 research/design methods and 15 word/sound operations with sources, inputs, procedures, checks and catalog cross-references.
- Added a brand/campaign/scenario research-brief builder, record contract and handoff; full source URLs remain visible beside claims.
- Added INTERVIEW mode for questions before research, and a repository reference in every completed brief.
- Added operation selection, transformation lineage and diversity controls.
- Filled Role/CTA and hero/amplifier guidance; connected research to existing steps and human checkpoints.
- Added generated RESEARCH.md for AI without repository access.
- Full teaching material remains in PROMPT.md. The hosted runtime keeps its existing size budget by trimming extended examples and using a compact operator menu; dedicated Insight/GWTB calibration, Spotify and QLiEER remain in the runtime.
- Method version 1.1.0; release tagging and hosted deployment are separate.

### 2026-09-14 — Soundcheck for presentation arguments and titles

- Added the seven-principle Soundcheck method by Nicolas Chan to Deck Mode,
  the skill router, the compiled single-paste prompt and hosted-engine runtime.
- Structure before polish; audience-specific significance, one governing
  point as far as possible, flexible evidence sources and useful alternatives.
- Replaced the five-word title target and the instruction to write
  provocations; clarified the conditional role of the worked deck examples.
- The nine-step sequence and the Insight/Strategy pit stops are unchanged.

## [1.0.0] — 2026-09-02

First public release under the name Logic Poetry.

- Nine-step chain with two mandatory pit stops (Insight, Strategy).
- Logic Stack check between Steps 3 and 4.
- Get-Who-To-By strategy engine with WHO/FROM forms and quality rubric.
- Creative Techniques Catalog, clusters A to L, with source bibliography.
- Debugging suite, creative moves, validation checklist.
- Output models: Deck Mode, Session Recap, Performance Snapshot.
- Three-language configuration (working / delivery / creative priority).
- Calibration examples: insight chains, twelve campaign cases, GWTB calibration, one full model answer.
- Modular layout plus a generated single-paste `PROMPT.md`.
- Frontmatter on every module; `frameworks/` plug-in folder seeded with thirteen entries migrated from catalog cluster J; case library with generated `examples/INDEX.md` and `dist/index.json`; compiler check runs in CI.

Lineage: this release carries forward the author's privately developed method (internal version 6.0). Earlier versions were never published.
