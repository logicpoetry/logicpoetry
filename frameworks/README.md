# Plug-in frameworks

Other people's methods, and new ones, that plug into the Logic Poetry chain at a named step. The chain is fixed. What you run inside a step is open.

Each framework is one file built from `_TEMPLATE.md`. The first thirteen were migrated from the techniques catalog (cluster J) as seed entries: one line each, awaiting a full write-up. Open a pull request to finish one, or to add your own.

## Admission test

A framework belongs here only if it:

- is a specific, recognisable creative move or method;
- changes how an idea is generated, framed, dramatised or executed;
- can be explained clearly enough for someone else to use;
- is supported by a credible source or a documented project example; and
- adds something not already expressed more fully in the chain itself or in the catalog.

Excluded: general brainstorming methods, brief-writing templates, generic process advice, unnamed inspiration dressed as technique, and duplicates.

## Entry format

Every entry carries the seven headings in `_TEMPLATE.md`: what it does, when to use it, how to apply it, failure mode, example, source and confidence. The build check rejects entries missing any of them.
